# Excalidraw and bundled fonts

Excalidraw 0.18.1 is distributed under the MIT license in `Excalidraw-LICENSE.txt`.
The fonts retain their own licenses; Sidequest's application license does not replace them.

Font notices were retained from the exact package's embedded WOFF2 name tables.
For subset fonts with stripped name tables (Excalifont, Comic Shanns, Xiaolai),
they were retained from the original name-table comments in the corresponding
[`fonts/<family>/index.ts` at v0.18.1](https://github.com/excalidraw/excalidraw/tree/v0.18.1/packages/excalidraw/fonts).

Assistant, Excalifont, Liberation Sans, Lilita One, Nunito, Virgil and Xiaolai
use the SIL Open Font License 1.1 (`OFL-1.1.txt`) and the copyright notices in
their respective files. Comic Shanns uses the MIT license in `ComicShanns.txt`.
Cascadia Code's embedded license and copyright notice are in `Cascadia.txt`.
The font binaries, including their embedded metadata, are copied without modification.
